Bank Lending Dashboard

Project Overview

The Bank Lending Dashboard is a data analytics project designed to analyze loan applications, lending performance, borrower characteristics, and loan repayment trends. The project transforms raw lending data into meaningful insights to support data-driven decision-making and help financial institutions monitor their lending activities.

Project Objectives

* Analyze total loan applications and lending performance.
* Monitor funded amounts and amounts received.
* Compare good loans and bad loans.
* Identify trends in loan applications and borrower behavior.
* Evaluate loan performance across different borrower and loan categories.
* Present key performance indicators through an interactive dashboard.

Key Performance Indicators (KPIs)

The dashboard focuses on the following metrics:

* Total Loan Applications: Number of loan applications received.
* Total Funded Amount: Total value of loans issued.
* Total Amount Received: Payments received from borrowers.
* Average Interest Rate: Average interest rate across loans.
* Average Debt-to-Income Ratio (DTI): Average proportion of borrowers’ income allocated to debt.
* Good Loan Percentage: Share of loans classified as good loans.
* Bad Loan Percentage: Share of loans classified as bad loans.

Dashboard Features

* Summary Analysis: Overview of lending performance using key metrics.
* Loan Status Analysis: Breakdown of loans by repayment and default status.
* Monthly Trends: Analysis of changes in loan applications and funded amounts over time.
* Borrower Analysis: Insights into borrower characteristics and financial profiles.
* Loan Purpose Analysis: Comparison of loans across different purposes.
* Geographical Analysis: Exploration of lending activity across regions, where location data is available.

 Tools & Technologies

* Power BI — Interactive dashboard development and data visualization.
* Microsoft Excel — Data preparation, cleaning, and preliminary analysis.
* Power Query — Data transformation and preparation.
* DAX — Creation of calculated measures and KPIs.
